# Getting Started

Learn how to install and configure Auto Uploader for Obsidian.

---

## Overview

Auto Uploader helps you automatically upload images and videos from your Obsidian vault to cloud storage providers. Once configured, simply drop media files into your watch folder, and the plugin will:

1. Detect the new file
2. Upload it to your configured provider
3. Insert the public URL at your cursor position

## Requirements

- Obsidian 1.6.0 or higher
- A cloud storage account (Cloudflare R2, AWS S3, or YouTube)
- API credentials for your chosen provider
