## Quick Installation (3 Steps)

### Step 1: Run the Installation Script

Open PowerShell in the plugin folder and run:

```powershell
.\install-to-obsidian.ps1
```

The script will:
- Check that all required files exist
- Ask for your Obsidian vault path
- Copy all plugin files to the correct location
- Show you next steps

**Example vault paths:**
- `C:\Users\YourName\Documents\MyVault`
- `C:\Users\YourName\Vault`
- Or wherever your Obsidian vault is located

---

### Step 2: Enable Plugin in Obsidian

1. Open Obsidian
2. Go to **Settings** (gear icon in bottom left)
3. Click **Community plugins** in the left sidebar
4. If you see "Restricted mode is enabled", click **Turn off restricted mode**
5. Scroll down to find **Auto Uploader** in the "Installed plugins" section
6. Toggle the switch to **ON** (it should turn blue)

---

### Step 3: Configure Storage Provider

1. In Obsidian Settings > **Community plugins** > Click the **gear icon** next to "Auto Uploader"
2. Under **Image Provider**, select your preferred provider:
   - **Cloudflare R2** - Recommended for most users
   - **S3 / Hetzner / Supabase / Generic S3** - For other S3-compatible storage
3. Fill in your credentials (see provider-specific guides)

{: .note }
> Don't have R2 credentials yet? See the [Cloudflare R2 Setup Guide]({{ site.baseurl }}/storage-providers/cloudflare-r2/).

## Manual Installation

If the script doesn't work, you can install manually:

### 1. Find Your Vault Path

Your Obsidian vault is usually in:
- `C:\Users\YourName\Documents\YourVaultName`
- Or check in Obsidian: Settings > About > Vault location

### 2. Create Plugin Folder

```powershell
$vaultPath = "C:\Path\To\Your\Vault"
$pluginFolder = "$vaultPath\.obsidian\plugins\auto-uploader"
New-Item -ItemType Directory -Force -Path $pluginFolder
```

### 3. Copy Files

```powershell
$sourcePath = "C:\Path\To\AutoUploader-Obsidian-plugin"
Copy-Item "$sourcePath\main.js" $pluginFolder
Copy-Item "$sourcePath\manifest.json" $pluginFolder
Copy-Item "$sourcePath\auth-helper.html" $pluginFolder
```

## Development Mode

For active development with auto-rebuild:

```powershell
npm run dev
```

This will:
- Watch for file changes
- Automatically rebuild when you save
- Keep running until you stop it (Ctrl+C)

After each rebuild:
1. In Obsidian, press **Ctrl+P** (Command Palette)
2. Type "reload app without saving"
3. Press Enter
4. Test your changes!

## Required Files

| File | Purpose |
|:-----|:--------|
| `main.js` | Compiled plugin code (generated by build) |
| `manifest.json` | Plugin metadata |
| `auth-helper.html` | YouTube OAuth helper (optional, for video uploads) |

All files should be in: `YourVault\.obsidian\plugins\auto-uploader\`

## Troubleshooting

### Plugin doesn't appear in Obsidian

- Make sure `main.js` and `manifest.json` are in `.obsidian\plugins\auto-uploader\`
- Restart Obsidian completely
- Check that Restricted Mode is OFF
- Verify the plugin folder name is exactly `auto-uploader`

### Upload fails

- Check credentials are correct
- Open console (Ctrl+Shift+I) to see error messages
- Verify your API token has proper permissions
- Make sure public access is enabled if using public URLs

### File not detected

- File must be in the `auto-upload/` folder (or your configured watch folder)
- Supported formats: PNG, JPG, JPEG, GIF, WebP, HEIC
- Try dragging directly into the folder view, not the note editor

### Build errors

```powershell
# Clean and rebuild
npm install
npm run build
```
